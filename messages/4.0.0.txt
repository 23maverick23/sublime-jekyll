Version 4.0.0 restores compatibility with current Sublime Text 4 and fixes
outstanding bugs in settings, path lookup, templates, uploads, and draft promotion.
It requires Sublime Text 4, build 4083 or later. ST3 users should stay on 3.1.7.

Paths now support ${project_path}, ${folder}, ~, and relative paths. Site folders
containing _config.yml or _config.yaml are detected automatically.

Breaking changes: support for ST2/ST3, settings migration commands, backup
browsing, and jekyll_utility_disable have been removed. Update old settings by
hand using the format in the documentation.

The package is now in maintenance mode and is no longer in active development.
No new features are planned. Bug-fix PRs may be reviewed as time allows.

This release was prepared with help from AI coding tools (Claude Code and
Codex). The maintainer reviewed the changes; testing combined automated checks,
agent-run checks in Sublime Text, and the maintainer's own testing.

Thanks for using sublime-jekyll!


Change Log
----------

## [4.0.0] - 2026-11-07
### Changed
- Require Sublime Text 4 build 4083+.
- Support relative paths and variables, and auto-detect Jekyll site roots.
- Use a draft's front-matter date when promoting it, or today's date as a fallback.
### Removed
- Remove ST2/ST3 support and legacy settings migration commands.
### Fixed
- Fix loading on Python 3.13+, menu errors, settings lookup, and path selection.
- Fix deletion, promotion, upload insertion, and template title escaping.
