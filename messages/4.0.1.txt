sublime-jekyll 4.0.1
===================

- Fix the package layout and remove empty keymaps for Package Control review.
- Open package defaults and User settings side by side from Preferences >
  Package Settings > Jekyll > Settings, or Preferences: Jekyll Settings in the
  Command Palette.

Requires Sublime Text 4, build 4083 or later. ST3 users should stay on 3.1.7.

Documentation: https://sublime-jekyll.readthedocs.io/
